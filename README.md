# Rehearsal

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-support-ffdd00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/loganshippee)

A Mac and Windows app (with a web version for any browser) for your classroom screen and music rehearsals. It switches classes by bell schedule and runs your timers, music, reminders and agenda on its own, and it has sight-reading, score practice and grading tools.

## Install (for teachers)

### Mac
1. Download **[Rehearsal.zip](https://github.com/LoganShippee/rehearsal/releases/latest/download/Rehearsal.zip)** from the latest release.
2. Double-click the zip and drag **Rehearsal** into Applications. Open it from Applications, not from Downloads: macOS runs apps left in Downloads from a hidden read-only copy, which can block the microphone and updates.
3. Open it. macOS says it can't check the developer, because the app isn't registered with Apple: click **Done**, then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. This is needed only once.

### Windows (Windows 10 / 11)
1. Download **[Rehearsal-Setup.exe](https://github.com/LoganShippee/rehearsal/releases/latest/download/Rehearsal-Setup.exe)** from the latest release (or the portable zip **[Rehearsal-Windows.zip](https://github.com/LoganShippee/rehearsal/releases/latest/download/Rehearsal-Windows.zip)**).
2. Run **Rehearsal-Setup.exe**. Windows Defender SmartScreen may show *"Windows protected your PC"* because the app isn't code-signed yet: click **More info → Run anyway**. This is needed only once.
3. Rehearsal installs for your user account (`%LOCALAPPDATA%\Programs\Rehearsal`) with **no administrator password required** — ideal for school PCs.

**Updates are automatic.** Rehearsal checks GitHub when it opens and every few hours. Most updates download quietly and are used the next time it opens (or click **Restart now**). Updates to the app itself show **Install and reopen**. Settings → Updates shows the version and has **Check for updates**. Every update is signed; the app refuses one whose signature doesn't match. Your classes and files are never touched by an update.

## Web version (any browser)
Open **https://app.rehearsalmusic.com/** (or mirror **https://loganshippee.github.io/rehearsal/**) in any browser: Chrome, Safari, Edge or Firefox, on a Windows PC, Chromebook, Mac or iPad. It works offline after the first visit. To make it feel like an app, install it: in Chrome or Edge use **Install Rehearsal** in the address bar (or the ⋮ menu); on an iPad tap **Share → Add to Home Screen** in Safari, then open it from the Home Screen to run it full screen. On an iPad it works best with a keyboard for now (touch controls come later). It updates itself: each new release is live the next time it's opened online. Settings → Updates (at the top) has **Check for updates**; if a newer version is out, **Reload now** switches to it.

The web version keeps its classes and files in that browser on that device only. Use Settings → Export backup to move data between devices. Desktop-only features (Mac & Windows): MuseScore files (.mscz; MusicXML works), Google Drive browsing, full-browser windows, and automatic dated backups. Mac-only: live windows from other apps.

## For the developer
- `./build.sh --install` builds `build/Rehearsal.app` and copies it into Applications (for trying changes on your own Mac).
- `./release.sh "What changed"` publishes a new version to everyone (`--minor` / `--major` for bigger version jumps). It runs the grader tests, raises the version in `release/VERSION`, commits, builds the Mac app locally and the Windows app/installer via GitHub Actions in parallel, signs and uploads all release files, and publishes the web folder to GitHub Pages (the iPad version). If `native/` or `build.sh` changed, Mac users get a full app update (and likewise `windows/` for Windows users); otherwise only the web files.
- **Release key:** `~/.rehearsal/release-key` signs every update. **Back it up** (e.g. in a password manager). Without it you can't publish updates that existing copies will accept. Never put it in the repository. The matching public key is `release/public-key.txt`.
- `tests/run.sh` runs the grader tests. The app icon's artwork is `icon/source-1024.png` (made with IconKitchen; its web icons are in `web/`). To rebuild the Mac icon from it: `swift icon/fromimage.swift icon/source-1024.png build/AppIcon.iconset && iconutil -c icns build/AppIcon.iconset -o icon/AppIcon.icns`.
- The app's internal ID is `local.rehearsal.app` and its data folder is `~/Library/Application Support/Rehearsal/` (existing data from the legacy folder is migrated automatically on first launch).

## What's in it
- **Present screen:** clock, time left in the period, agenda that moves forward on its own, warm-up question, and resource tabs (Google Slides/Docs/Sheets/Forms/Drive, YouTube, Canva, PDFs, pictures, videos). Use the 📌 menu in the toolbar to show any class off-schedule.
- **Online Homework (optional teacher add-on):** create classes with 6-character join codes and personal student codes (with printable cut-out code sheets and a projector-ready Join Code view), assign Sight Reading (Practice or True Sight-Read with study timer), Score Practice (MusicXML), or Audio-Only exercises directly from the Present screen or Setup → Homework, and review submissions in the Gradebook with audio playback, student-matching visual grading feedback, teacher overrides/comments, and CSV/JSON export — while keeping the local classroom app free and offline-first. See [`web/privacy.html`](web/privacy.html), [`docs/SDPC-Privacy-Summary.md`](docs/SDPC-Privacy-Summary.md), [`docs/IT-Admin-Google-Whitelisting.md`](docs/IT-Admin-Google-Whitelisting.md), and [`tools/hw-worker/DEPLOY.md`](tools/hw-worker/DEPLOY.md).
- **Windows on the Present screen:** **＋ Window** in the toolbar opens a web page or search, a PDF/picture/video from your Mac, a class resource, the warm-up, or a Library file, all without going into Edit. Drag a window by its title bar, resize it from the corner, double-click the title bar to maximize it, and use **▦ Tile** to arrange everything in a grid. Each class remembers its own windows. 📌 saves a window to the class's resources.
  - Web windows start **embedded**. If a site won't show (Google Search, many news sites), click **Full browser**: every site works and stays signed in. Timers and pop-up messages still show on top, and drawing works over it while Annotate is on. Searches typed in the address bar open in full-browser mode automatically.
- **Other apps' windows (e.g. MuseScore):** ＋ Window → *Window from another app* shows a live copy of that app's window. Clicks, scrolling, typing and ⌘-shortcuts (except ⌘Q) go through to the app. Keep the real app open behind Rehearsal. **Open MuseScore** on the window's bar switches to the real app for heavy editing. This needs two one-time permissions in System Settings → Privacy & Security: *Screen & System Audio Recording* (to see the window) and *Accessibility* (to click and type in it). Because the app is self-built, macOS asks for these again after each rebuild.
- **Sight-reading generator:** ＋ Window → 🎼. **Rhythm** examples (**Numbers** `1 e & a`, **Kodály** `ta / ti-ti / tika-tika`, or **Takadimi** `ta / ta-di / ta-ka-di-mi`; simple and compound meters; choose which note values and rests appear) and **Solfege** melodies (movable do, do-based minor; key, clef, range, how far the melody leaps). Save and load your own named presets in ⚙ Settings (each preset updates every rhythm, meter, key, and range option visibly). Playback with a count-in and metronome, measure numbers, a playhead shown as two steady marks above and below the staff (never covering notes), a count-in for both rhythm and solfege (solfege can sound do, the starting pitch or the tonic chord first), live changes to tempo, metronome and display while playing, a show/hide answers toggle, **Worksheet** with a live scrollable preview where you can swap or reorder individual exercises before printing a 1–6 exercise sheet with a Page 2 Teacher Answer Key, and 💾 to save an example to a class as a tab. Melodies are built from patterns by default (⚙ → Melody: a motif, then sequences a step up or down, then a cadence; 8 measures = question / answer phrases), or Free. ✏️ Build makes your own example (one creator: 🥁 Rhythm only in the top bar shows the same example as a rhythm line): click notes, rests or groups (rows for each), then syllables (low sol … high mi) — a syllable adds the highlighted rhythm; click a note to select it (↑ ↓ re-pitch, ← → move, Delete, ⌘Z undo), Clear measure / all, 💾 save. Measures always add up: a long note that won't fit is tied over the bar line, ⌒ Tie ties the selected note to the next, deleting in the middle leaves a rest. Rhythm blocks are shown as notation. ⚙ → Tied notes adds ties to generated examples too. The Solfege tab has 🔢 Show counts (counts under the syllables) and 🥁 Rhythm only (the melody's rhythm on one line, clapped). Solfege can have 2 or 3 parts (⚙ → Parts): Harmony (lines written over a I–IV–V–vi progression, same or different rhythms per part; Unison: lots / some / none — how often parts sing the same note) or Canon (each part enters 1 or 2 measures later); each part has its own staff and clef. **A− / A+** make the music bigger or smaller for projecting. **Playhead: Beat / Note / Off** (defaults to Beat) switches how the playhead moves. Space plays/stops. Click any measure to start playback there (green ▶ flag; click it again, or click measure 1, to go back to the start). Drag any toolbar button to rearrange it with a live landing preview (⚙ → Reset toolbar restores the standard layout). Notation uses VexFlow (`web/vendor/vexflow.js`, open source, bundled for offline use).
- **Classroom piano & vocal warm-up** (＋ Open → **Piano**): a 2.5-octave playable grand piano (click, slide, or toggle **Keys** to play with your computer keyboard `A–;`, `Z/X` to shift octaves) with key-aware enharmonic black-key labels, dynamic movable-do solfege labels, Sustain, quick `I–vi` chords in any key, and a hands-free **Warm-up sequencer** with 12 choir vocalizes (5-note scale, Rossini 9-note scale, thirds agility, Zing-a-Mama, staccato triad, siren, etc.), live VexFlow staff notation with solfege and optional rhythm counts, and modulating `V7 → I` chord changes between keys. Pin it (📌) to keep it as a class tab.
- **Solfege board** (＋ Open → **Solfege board**): a projectable pitch ladder or grid with Major, Minor, Pentatonic, Chromatic (♯), and Chromatic (♭) scales, all 17 authentic Curwen hand-sign illustrations, Boomwhacker/Kodály pitch colors (or neutral theme colors), full computer-keyboard play (`Z/X/C` for low `sol,–ti,`, `1–8` for `do–do'`, `A–G` for chromatic syllables), a **Recent echo trail** with one-click replay, and a **Mystery echo** mode that plays a hidden pattern and reveals it on click.
- **Audio track player:** Library audio files (`.mp3`, `.m4a`, `.wav`, etc.) opened as a class tab or floating window display an interactive waveform player with click-to-seek, drag-to-loop A–B sections, pitch-preserving playback speed (`0.5×`–`1.25×`), optional 4-beat count-in, and saved named rehearsal markers (`M` to drop, `[` / `]` to jump).
- **Grading sight reading:** 🎤 Grade ▾ asks how to grade (your last choice is highlighted). Rhythm-only examples are always tapped (clapping into the mic was too unreliable to grade); single-line solfege can be sung or tapped. **Microphone** listens to singing (rhythm and pitch) with a live mic level indicator and quick sync calibration right from the grade menu or report. **Tap (Space / touch)** grades rhythm with no mic: after the count-in, press the space bar or tap the on-screen **Tap here** button (for iPad and touchscreens) once at the start of each note (a held or tied note gets one tap; rests get none). While grading is starting or running, Space never plays the example; press the Grade button again to stop early. After either kind of grading, the result is drawn on the music: notes turn green (on time), orange (early / late), red with a dashed ring (not heard / no tap) or purple (wrong pitch, with the note that was sung, or "oct ↑/↓"). A dotted lane above each staff shows when each note was heard (dot) against where it's written (tick), and × marks sounds or taps that matched no note. Hide marks (on the report) or ✕ Clear marks (on the music) removes them. The marks stay after you close the report and go away when you press New or grade again. **▶ Listen back** (on the report) plays your take — the mic recording, or your taps as clicks — lined up with the example from bar 1 at the tempo you performed, with the playhead and the marks; your steady delay is taken out, so you hear each note against perfect timing. Choose *with the example* or *recording / taps only*; Space or Stop ends it.
- **Tuner & drone** (🎯 in the toolbar): mic tuner with a needle and cents, note names for Concert / B♭ / E♭ / F instruments. The drone plays a single note, root + 5th (+ octave), or a major/minor chord, in an organ, sine or strings sound, with optional pure (just) intervals.
- **Metronome** (🥁): a huge beat count with beat 1 highlighted, accent patterns (e.g. 3+3+2), 8th/triplet/16th subdivisions, tap tempo, and a 1-bar count-off. It keeps running while you open other windows and stops when you close it. 📌 on the Tuner or Metronome window pins it to the class as a tab.
- **Toolbar:** buttons that don't fit on a small screen (iPad, laptop) move into the **⋯** menu at its end, along with Scores, Copy/paste and Tile (tick "in ⋯" in Customize toolbar to choose which). After a few idle seconds it shrinks to a small square in the middle of where it sits; move the mouse near the square (or tap it) to bring it back. Drag the ⋮⋮ grip to move it anywhere. Near a side edge it turns vertical, and dropping it at the top middle puts it back in the header. ⋯ opens a checklist to show/hide and drag-reorder its buttons, turn labels on or off, or reset it.
- **Class tabs:** drag a tab onto the middle of another to make a folder (one tab with a ▾ drop-down; drag more in, ⇱ to take one out, double-click to rename); double-click a tab (or a window's title) to rename it; hover a tab and click ✕ to remove it from the class. ⤢ maximizes the stage, hiding everything but the toolbar so Annotate, Board and timers still work. Pinch to zoom a tab, PDF or picture (the % badge resets it).
- **✏️ Quick edit** (toolbar): edit right on the Present screen. Click the class name, subtitle, warm-up or an agenda step to retype it. Agenda steps can be dragged (≡), re-timed and removed (✕), and clicking a step's number makes it current. You can also add today's announcements and birthdays, write today's notes, change this period's times, drag tabs to reorder, and double-click a tab to rename it. 🎨 Look changes colors, theme, picture and background dimming, and ⚡ Automations opens the class timeline in a side drawer.
- **Class screen:** drag the divider between the agenda panel and the stage to resize them. Double-click it, or use its button, to hide the panel. Remembered for each class.
- **Windows:** ▦ tiles a single window, pinch zoom works on any window, and web windows have a bookmarks bar (☆ to add, or import from Chrome in Settings).
- **Automations (per class):** at *N minutes after start* or *before end*: show a message, start a timer, play a sound, start or stop music, switch the resource, jump to an agenda step, show or clear a signal.
- **Daily routines:** the same actions at a set clock time on chosen weekdays.
- **Bell schedules:** a schedule for each weekday, plus special days (early release, no school).
- **Score practice:** ＋ Window → 🎹 Practice a score. Opens MusicXML (.mxl/.musicxml) or MuseScore (.mscz/.mscx — converted once with the installed MuseScore 4) as real notation (OpenSheetMusicDisplay, bundled in `web/vendor/osmd.min.js`) with piano playback (`web/vendor/piano.js`, FluidR3 grand piano). Choir tools: Focus a voice (others soft), 🔔 starting pitches per section (or low→high / together), Show voices only or the focus part only for projecting. Click a measure to select it (highlighted in blue), Shift-click or drag to select more; 🔁 Loop repeats the selection (optionally counting in before every repeat), otherwise Play starts there, with a split playhead above/below the staff and a count-in matching Sight Reading, parts and volumes, tempo stepper showing % of original with one-click reset (click BPM to type a tempo directly), count-in, metronome, starting pitches and speed-up on each loop repeat. Space plays/stops. 🗂 Classes: tick classes to give them a permanent 🎹 Scores tab (opens to the last score used there). Repeat signs and 1st / 2nd endings are followed in playback (a loop picks the ending that belongs to the measures you select); D.C. / D.S. / Coda are not. ✎ (next to ⚙) chooses which controls are shown, for every score. 🔢 Measure # numbers every measure; 🎵 Solfege / 🥁 Counts write syllables (movable do; follows key changes and detects minor sections from the music; do- or la-based minor in ⚙; hover Solfege to see the keys found) or 1 e & a counting under each focused voice (below the lyrics) (all voices if none focused). ⚙ → Sound / playhead sync shifts the playhead to match your speakers (shared with sight reading). Every score you open stays in the list at the top of the widget (🎼 dropdown) — switch scores there, ＋ add more, ✕ remove; each score remembers its own loop, spots, focus and tempo, and 🎹 Scores (toolbar) / ＋ Window → Score practice reopens the last one. Rehearsal: parts you hear are coloured (focused part strongest, muted parts grey); 📋 Spots saves loops with their focus part and tempo to step through (◀ ▶) and tick off; ↕/↔ switches between scrolling down the page and one long sideways line. Pin it (📌) to keep it as a class tab.
- **Announcements per class:** each event/announcement/birthday can show in all classes or only the ones ticked under "Show in" (Setup → Events); adding one on the Present screen (Quick edit) offers This class / All classes. Double-click any agenda step on the Present screen to change its text (Enter saves, Esc cancels).
- **Toolbar:** ⋯ on the toolbar: tick what shows, drag ≡ to reorder, set each button's emoji, labels on/off, emojis on/off, size (small/medium/large), colour (dark/light/class colour), see-through, hide-when-idle (never / 3 / 10 / 30 s), and quick spots (top, bottom, left, right).
- **Icons:** 😀 Icons (toolbar ⋯, Quick edit, or the Edit screen's class page) turns emojis on/off for tabs, toolbar, window titles and announcements, and picks the emoji for each tab, each tab type, each toolbar button and each announcement type (empty = default, `-` = none). The ❓ Warm-up tab can be removed per class with its ✕ (bring it back in Quick edit or Setup → Classes).
- **Copy / paste between classes:** 📋 Copy/paste (toolbar, Quick edit, or the Edit screen's class page). Tick pinned tabs, agenda, warm-up and/or look, press Copy, switch class, press Paste. Tabs are added; if the class already has an agenda you choose add-to-end or replace.
- **Tools:** timer, team points, noise meter (microphone), student randomizer and group maker, signals, plus annotation (draw over slides) and a blank whiteboard. Annotate has a clear **Draw | Interact** switch (so you can pause drawing to click slides or web pages), keeps separate drawings per tab and on the Whiteboard, and offers an Undo toast after Clear. PDFs open in Rehearsal's own viewer (page or unlimited lazy scroll, click page number to jump, fit page/width, crisp zoom, arrow-key or pedal page turns, built-in PDF annotation, and Download PDF with annotations).
- **Calendar** (＋ Window, or ⋯ in the toolbar): a month view with days off, special bell schedules, events and birthdays. Click a day to change its bell schedule (or make it No school), give it a colour and a label (Concert, Exam week…), add events, announcements and birthdays (for all classes or one), and write that day's on-screen note.
- **Progress tracker** (＋ Window, or ⋯ in the toolbar): one list per class of pieces or tasks, each with a colour (click the light or its label to pick): red = haven't started, yellow = still working, green = concert ready. Add steps and check them off (a bar shows how far along it is; checking the first step turns red to yellow, and once every step is done it offers green), write notes, reorder with the arrows, and rename the three colours with Labels. 📌 pins the Calendar or the tracker to a class as a tab.
- **Notes on screen:** Setup → Notes & print (or Quick edit) has *Notes on screen* for each class and day. Students see them on the Present screen under Today.
- **Notes & print:** daily notes for each class, printable notes, and one-click sub plans. Choose "Save as PDF" in the print window to share them.
- **Recorder** (＋ Window, or ⋯ in the toolbar): check the mic level, then press the red button. Start right away, after a count-in, or with a count-in and a click that keeps going (optionally kept out of the recording with echo cancellation). While recording: live waveform, Pause, Stop, and Mark (or press M) to flag spots. When you stop it asks “Keep this recording?”: listen back, drag on the waveform to loop a section, slow it to 0.75× or 0.5×, add or remove markers, trim to the looped section, name it, then Save or Delete. Saved recordings (Today / Earlier, with a mini waveform) open in the same player; A/B compares two takes at the same moment; the export button saves a copy (Mac) or shares it (iPad: AirDrop, Files…).
- **Tuner:** the gauge now matches the ±50¢ marks, turns green / yellow / red, and locks in (✓ glow) after a second in tune. A trace under it shows the last few seconds of pitch. The full-screen button gives a big view for the whole room. Settings sit behind the sliders button. The drone is a one-octave keyboard (chord notes light up) with chord buttons and an optional slow fade-in.
- **Metronome:** big tempo (drag it up or down) with its Italian marking; the window edge flashes on each beat (stronger on beat 1). Tap a beat number to accent or silence it. Swing for 8ths, saved tempos per piece, and under More options: speed trainer (+N BPM every N bars), gap-click (play N bars, silent N bars), ramp and sync.
- Tuner, Metronome and Recorder shrink gracefully: extras hide first, the main controls stay.
- **YouTube** (＋ Window, or ⋯ in the toolbar): paste a video or playlist link to play it in a window. Videos you play are kept under **Recent**; make **Playlists** and step through them with ‹ › (auto plays the next one when a video ends). The pin button pins it to the class as a tab, or leave it floating.
- **Board paper:** the Board can show music staff, a grand staff or a grid (the Paper menu on the drawing toolbar). Clear erases your writing, not the lines.
- **Progress in the side panel:** tick "Show the Progress tracker in the side panel" in Setup → Classes, or press **Side panel** in the Progress window.
- **Sound and playhead sync** (Settings): music volume for sight reading and scores (with a limiter, so it can go louder without distorting), and the playhead delay, which you can set by tapping along with 8 clicks (Calibrate…). Both are kept per device. On iPad, Rehearsal now asks Safari for normal playback volume and only switches to record mode while a microphone is on.
- **Window menu:** the window types are a grid of buttons at the top; the class's tabs and the Library are collapsible lists (the Library starts closed), with a search box when there are many.
- **Events:** birthdays (with confetti), announcements, and school events. You can import Google Calendar `.ics` files.
- **Library:** music and sound files, PDFs and pictures, stored on this Mac.
- **Test mode** (Settings): pretend it's a different time to watch automations run.

Keyboard on the Present screen: ← → move the agenda, Esc closes pop-ups and annotation, ⌘E opens Setup, ⌃⌘F toggles full screen.

## Google Drive (school accounts)
Setup → Classes → Resources → **Browse Google Drive…** opens the real Drive in its own window. Sign in there like in Safari; school sign-in pages work. Open a file, then click **Use this file**. This avoids school blocks on "Sign in with Google" apps, because there's no API and nothing for an admin to approve.

If a Google file on the Present screen shows "You need access", use the **Drive window** button on that tab.

## Your data

**Automatic backups:** each day you use the app, the first save keeps a dated copy of your data in `~/Library/Application Support/Rehearsal/backups/` on Mac or `%LOCALAPPDATA%\Rehearsal\backups\` on Windows (newest 30 kept). Setup → Settings → Automatic backups lists them with **Restore** (what you have now is backed up first) and **Back up now**.

**Fast score tabs:** a few seconds after opening (and when the class changes) the app quietly loads the notation library, the piano, and this class's scores, and draws its first score tab off-screen so it opens instantly.
Everything is saved in `~/Library/Application Support/Rehearsal/` on Mac or `%LOCALAPPDATA%\Rehearsal\` on Windows (`data.json` plus a `files/` folder). Use Settings → Export backup to move it to another computer.
