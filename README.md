# Rehearsal

A Mac (and iPad) app for your classroom screen and music rehearsals. It switches classes by bell schedule and runs your timers, music, reminders and agenda on its own, and it has sight-reading, score practice and grading tools.

## Install (for teachers)
1. Download **Rehearsal.zip** from the latest release: `https://github.com/LoganShippee/rehearsal/releases/latest/download/Rehearsal.zip`.
2. Double-click the zip and drag **Rehearsal** into Applications. Open it from Applications, not from Downloads: macOS runs apps left in Downloads from a hidden read-only copy, which can block the microphone and updates.
3. Open it. macOS says it can't check the developer, because the app isn't registered with Apple: click **Done**, then go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. This is needed only once.

**Updates are automatic.** Rehearsal checks GitHub when it opens and every few hours. Most updates download quietly and are used the next time it opens (or click **Restart now**). Updates to the app itself show **Install and reopen**. Settings → Updates shows the version and has **Check for updates**. Every update is signed; the app refuses one whose signature doesn't match. Your classes and files are never touched by an update.

## iPad
Open **https://loganshippee.github.io/rehearsal/** in Safari, tap **Share → Add to Home Screen**, then open Rehearsal from the Home Screen. It runs full screen and works offline after the first visit. It's built for an iPad with a keyboard for now (touch controls come later). It updates itself: each new release is live the next time it's opened online. Settings → Updates (at the top) has **Check for updates**; if a newer version is out, **Reload now** switches to it.

The iPad version keeps its classes and files on that iPad only, in Safari's storage. Use Settings → Export backup to move data between devices. Mac-only features: windows from other apps, MuseScore files (.mscz; MusicXML works), Google Drive browsing, and automatic dated backups.

## For the developer
- `./build.sh --install` builds `build/Rehearsal.app` and copies it into Applications (for trying changes on your own Mac).
- `./release.sh "What changed"` publishes a new version to everyone (`--minor` / `--major` for bigger version jumps). It runs the grader tests, raises the version in `release/VERSION`, commits, builds, signs and uploads, and publishes the web folder to GitHub Pages (the iPad version). If anything in `native/` or `build.sh` changed, users get a full app update; otherwise only the web files.
- **Release key:** `~/.rehearsal/release-key` signs every update. **Back it up** (e.g. in a password manager). Without it you can't publish updates that existing copies will accept. Never put it in the repository. The matching public key is `release/public-key.txt`.
- `tests/run.sh` runs the grader tests. `swift icon/makeicon.swift --preview out.png <style>` previews icon designs.
- The app's internal ID (`local.classpilot.app`) and data folder (`~/Library/Application Support/ClassPilot/`) keep the app's old name on purpose, so permissions, sign-ins and data carry over.

## What's in it
- **Present screen:** clock, time left in the period, agenda that moves forward on its own, warm-up question, and resource tabs (Google Slides/Docs/Sheets/Forms/Drive, YouTube, Canva, PDFs, pictures, videos). Use the 📌 menu in the toolbar to show any class off-schedule.
- **Windows on the Present screen:** **＋ Window** in the toolbar opens a web page or search, a PDF/picture/video from your Mac, a class resource, the warm-up, or a Library file, all without going into Edit. Drag a window by its title bar, resize it from the corner, double-click the title bar to maximize it, and use **▦ Tile** to arrange everything in a grid. Each class remembers its own windows. 📌 saves a window to the class's resources.
  - Web windows start **embedded**. If a site won't show (Google Search, many news sites), click **Full browser**: every site works and stays signed in. Timers and pop-up messages still show on top, and drawing works over it while Annotate is on. Searches typed in the address bar open in full-browser mode automatically.
- **Other apps' windows (e.g. MuseScore):** ＋ Window → *Window from another app* shows a live copy of that app's window. Clicks, scrolling, typing and ⌘-shortcuts (except ⌘Q) go through to the app. Keep the real app open behind Rehearsal. **Open MuseScore** on the window's bar switches to the real app for heavy editing. This needs two one-time permissions in System Settings → Privacy & Security: *Screen & System Audio Recording* (to see the window) and *Accessibility* (to click and type in it). Because the app is self-built, macOS asks for these again after each rebuild.
- **Sight-reading generator:** ＋ Window → 🎼. **Rhythm** examples (1 e & a counting; simple and compound meters; choose which note values and rests appear) and **Solfege** melodies (movable do, do-based minor; key, clef, range, how far the melody leaps). Playback with a count-in and metronome, measure numbers, a playhead shown as two steady marks above and below the staff (never covering notes), a count-in for both rhythm and solfege (solfege can sound do, the starting pitch or the tonic chord first), live changes to tempo, metronome and display while playing, a show/hide answers toggle, and 💾 to save an example to a class as a tab. Melodies are built from patterns by default (⚙ → Melody: a motif, then sequences a step up or down, then a cadence; 8 measures = question / answer phrases), or Free. ✏️ Build makes your own example (one creator: 🥁 Rhythm only in the top bar shows the same example as a rhythm line): click notes, rests or groups (rows for each), then syllables (low sol … high mi) — a syllable adds the highlighted rhythm; click a note to select it (↑ ↓ re-pitch, ← → move, Delete, ⌘Z undo), Clear measure / all, 💾 save. Measures always add up: a long note that won't fit is tied over the bar line, ⌒ Tie ties the selected note to the next, deleting in the middle leaves a rest. Rhythm blocks are shown as notation. ⚙ → Tied notes adds ties to generated examples too. The Solfege tab has 🔢 Show counts (counts under the syllables) and 🥁 Rhythm only (the melody's rhythm on one line, clapped). Solfege can have 2 or 3 parts (⚙ → Parts): Harmony (lines written over a I–IV–V–vi progression, same or different rhythms per part; Unison: lots / some / none — how often parts sing the same note) or Canon (each part enters 1 or 2 measures later); each part has its own staff and clef. **A− / A+** make the music bigger or smaller for projecting. **Playhead: Beat / Note / Off** switches how the playhead moves. Space plays/stops. Click any measure to start playback there (green ▶ flag; click it again, or click measure 1, to go back to the start). Notation uses VexFlow (`web/vendor/vexflow.js`, open source, bundled for offline use).
- **Grading sight reading:** On rhythm lines, 🎤 Grade ▾ asks how to grade (your last choice is highlighted); solfege is always graded with the microphone. **Microphone** listens to singing or clapping (rhythm, plus pitch for solfege). **Space bar** grades rhythm only with no mic: after the count-in, press the space bar once at the start of each note (a held or tied note gets one tap; rests get none). While grading is starting or running, Space never plays the example; press the Grade button again to stop early. After either kind of grading, the result is drawn on the music: notes turn green (on time), orange (early / late), red with a dashed ring (not heard / no tap) or purple (wrong pitch, with the note that was sung, or "oct ↑/↓"). A dotted lane above each staff shows when each note was heard (dot) against where it's written (tick), and × marks sounds or taps that matched no note. Hide marks (on the report) or ✕ Clear marks (on the music) removes them. The marks stay after you close the report and go away when you press New or grade again. **▶ Listen back** (on the report) plays your take — the mic recording, or your taps as clicks — lined up with the example from bar 1 at the tempo you performed, with the playhead and the marks; your steady delay is taken out, so you hear each note against perfect timing. Choose *with the example* or *recording / taps only*; Space or Stop ends it.
- **Tuner & drone** (🎯 in the toolbar): mic tuner with a needle and cents, note names for Concert / B♭ / E♭ / F instruments. The drone plays a single note, root + 5th (+ octave), or a major/minor chord, in an organ, sine or strings sound, with optional pure (just) intervals.
- **Metronome** (🥁): a huge beat count with beat 1 highlighted, accent patterns (e.g. 3+3+2), 8th/triplet/16th subdivisions, tap tempo, and a 1-bar count-off. It keeps running while you open other windows and stops when you close it. 📌 on the Tuner or Metronome window pins it to the class as a tab.
- **Toolbar:** buttons that don't fit on a small screen (iPad, laptop) move into the **⋯** menu at its end, along with Scores, Copy/paste and Tile (tick "in ⋯" in Customize toolbar to choose which). After a few idle seconds it shrinks to a small square in the middle of where it sits; move the mouse near the square (or tap it) to bring it back. Drag the ⋮⋮ grip to move it anywhere. Near a side edge it turns vertical, and dropping it at the top middle puts it back in the header. ⋯ opens a checklist to show/hide and drag-reorder its buttons, turn labels on or off, or reset it.
- **Class tabs:** drag a tab onto the middle of another to make a folder (one tab with a ▾ drop-down; drag more in, ⇱ to take one out, double-click to rename); double-click a tab (or a window's title) to rename it; hover a tab and click ✕ to remove it from the class. ⤢ maximizes the stage, hiding everything but the toolbar so Annotate, Board and timers still work. Pinch to zoom a tab, PDF or picture (the % badge resets it).
- **✏️ Quick edit** (toolbar): edit right on the Present screen. Click the class name, subtitle, warm-up or an agenda step to retype it. Agenda steps can be dragged (≡), re-timed and removed (✕), and clicking a step's number makes it current. You can also add today's announcements and birthdays, write today's notes, change this period's times, drag tabs to reorder, and double-click a tab to rename it. 🎨 Look changes colors, theme, picture and background dimming, and ⚡ Automations opens the class timeline in a side drawer.
- **Class screen:** drag the divider between the agenda panel and the stage to resize them. Double-click it, or use its button, to hide the panel. Remembered for each class.
- **Windows:** ▦ tiles a single window, pinch zoom works on any window, and web windows have a bookmarks bar (☆ to add, or import from Chrome in Settings).
- **Automations (per class):** at *N minutes after start* or *before end*: show a message, start a timer, play a sound, start or stop music, switch the resource, jump to an agenda step, show or clear a signal.
- **Daily routines:** the same actions at a set clock time on chosen weekdays.
- **Bell schedules:** a schedule for each weekday, plus special days (early release, no school).
- **Score practice:** ＋ Window → 🎹 Practice a score. Opens MusicXML (.mxl/.musicxml) or MuseScore (.mscz/.mscx — converted once with the installed MuseScore 4) as real notation (OpenSheetMusicDisplay, bundled in `web/vendor/osmd.min.js`) with piano playback (`web/vendor/piano.js`, FluidR3 grand piano). Choir tools: Focus a voice (others soft), 🔔 starting pitches per section (or low→high / together), Show voices only or the focus part only for projecting. Click a measure to select it, Shift-click or drag to select more; 🔁 Loop repeats the selection (optionally counting in before every repeat), otherwise Play starts there, choose parts and volumes, tempo slider, count-in, metronome, starting pitches and speed-up on each repeat. Space plays/stops. 🗂 Classes: tick classes to give them a permanent 🎹 Scores tab (opens to the last score used there). Repeat signs and 1st / 2nd endings are followed in playback (a loop picks the ending that belongs to the measures you select); D.C. / D.S. / Coda are not. ✎ (next to ⚙) chooses which controls are shown, for every score. 🔢 Measure # numbers every measure; 🎵 Solfege / 🥁 Counts write syllables (movable do; follows key changes and detects minor sections from the music; do- or la-based minor in ⚙; hover Solfege to see the keys found) or 1 e & a counting under each focused voice (below the lyrics) (all voices if none focused). ⚙ → Sound / playhead sync shifts the playhead to match your speakers (shared with sight reading). Every score you open stays in the list at the top of the widget (🎼 dropdown) — switch scores there, ＋ add more, ✕ remove; each score remembers its own loop, spots, focus and tempo, and 🎹 Scores (toolbar) / ＋ Window → Score practice reopens the last one. Rehearsal: parts you hear are coloured (focused part strongest, muted parts grey); 📋 Spots saves loops with their focus part and tempo to step through (◀ ▶) and tick off; ↕/↔ switches between scrolling down the page and one long sideways line. Pin it (📌) to keep it as a class tab.
- **Announcements per class:** each event/announcement/birthday can show in all classes or only the ones ticked under "Show in" (Setup → Events); adding one on the Present screen (Quick edit) offers This class / All classes. Double-click any agenda step on the Present screen to change its text (Enter saves, Esc cancels).
- **Toolbar:** ⋯ on the toolbar: tick what shows, drag ≡ to reorder, set each button's emoji, labels on/off, emojis on/off, size (small/medium/large), colour (dark/light/class colour), see-through, hide-when-idle (never / 3 / 10 / 30 s), and quick spots (top, bottom, left, right).
- **Icons:** 😀 Icons (toolbar ⋯, Quick edit, or the Edit screen's class page) turns emojis on/off for tabs, toolbar, window titles and announcements, and picks the emoji for each tab, each tab type, each toolbar button and each announcement type (empty = default, `-` = none). The ❓ Warm-up tab can be removed per class with its ✕ (bring it back in Quick edit or Setup → Classes).
- **Copy / paste between classes:** 📋 Copy/paste (toolbar, Quick edit, or the Edit screen's class page). Tick pinned tabs, agenda, warm-up and/or look, press Copy, switch class, press Paste. Tabs are added; if the class already has an agenda you choose add-to-end or replace.
- **Tools:** timer, team points, noise meter (microphone), student randomizer and group maker, signals, plus annotation (draw over slides) and a blank whiteboard. While annotating you see a brush preview, buttons and tabs stay clickable, a quick tap clicks what's underneath (a drag draws), and scrolling/pinch reach the page below. To click inside slides or web pages use 👆 Click slides. PDFs open in Rehearsal's own viewer (page or scroll, fit page/width, crisp zoom, page-turn pedals).
- **Calendar** (＋ Window, or ⋯ in the toolbar): a month view with days off, special bell schedules, events and birthdays.
- **Progress tracker** (＋ Window, or ⋯ in the toolbar): one list per class of pieces or tasks, each with a light (click to change): red = haven't started, yellow = still working, green = concert ready, plus notes on what still needs doing. 📌 pins the Calendar or the tracker to a class as a tab.
- **Notes on screen:** Setup → Notes & print (or Quick edit) has *Notes on screen* for each class and day. Students see them on the Present screen under Today.
- **Notes & print:** daily notes for each class, printable notes, and one-click sub plans. Choose "Save as PDF" in the print window to share them.
- **Events:** birthdays (with confetti), announcements, and school events. You can import Google Calendar `.ics` files.
- **Library:** music and sound files, PDFs and pictures, stored on this Mac.
- **Test mode** (Settings): pretend it's a different time to watch automations run.

Keyboard on the Present screen: ← → move the agenda, Esc closes pop-ups and annotation, ⌘E opens Setup, ⌃⌘F toggles full screen.

## Google Drive (school accounts)
Setup → Classes → Resources → **Browse Google Drive…** opens the real Drive in its own window. Sign in there like in Safari; school sign-in pages work. Open a file, then click **Use this file**. This avoids school blocks on "Sign in with Google" apps, because there's no API and nothing for an admin to approve.

If a Google file on the Present screen shows "You need access", use the **Drive window** button on that tab.

## Your data

**Automatic backups:** each day you use the app, the first save keeps a dated copy of your data in `~/Library/Application Support/ClassPilot/backups/` (newest 30 kept). Setup → Settings → Automatic backups lists them with **Restore** (what you have now is backed up first) and **Back up now**.

**Fast score tabs:** a few seconds after opening (and when the class changes) the app quietly loads the notation library, the piano, and this class's scores, and draws its first score tab off-screen so it opens instantly.
Everything is saved in `~/Library/Application Support/ClassPilot/` (`data.json` plus a `files/` folder). Use Settings → Export backup to move it to another Mac.

## Layout
- `native/`: Swift app shell (window, local loopback server, Drive window)
- `web/`: the app interface (HTML/CSS/JS)
- `build.sh`: builds `build/Rehearsal.app`
