1. How to Whitelist Google Sign-In in Google Admin Console

  1. Sign in at admin.google.com as a Super Administrator.
  2. Navigate to Security → Access and data control → API controls → Manage Third-Party App Access.
  3. Click Add app → OAuth App Name Or Client ID, then search for Rehearsal's production Google OAuth Client ID (<YOUR_GOOGLE_CLIENT_ID>.apps.googleusercontent.com — replace with your district/deployment Client ID).
  4. Select Trusted (recommended for assigned student/music OUs) or Limited so students and teachers on restricted school Google accounts can sign in cleanly.

Non-Sensitive Scopes Requested: openid, email, profile ONLY. Rehearsal never requests Google Drive, Google Classroom, Gmail, or Contacts scopes for Online Homework.

3. Chromebook, iPad & Desktop Readiness

  • Microphone Access: Ensure getUserMedia microphone access is allowed for the Student Portal origin on student Chromebooks and iPads.
  • Offline Drop Protection: Student recordings queue locally in browser IndexedDB if school Wi-Fi drops mid-class and auto-upload on reconnect.
  • Mac / Windows Desktop App: Teacher Google Sign-In opens the system default browser via 60-second one-time OAuth handoff polling — no embedded WebView login blocks.

4. Data Governance Summary for IT

  • 90-Day Media Expiry: Student audio blobs expire automatically in 90 days (R2 lifecycle + daily cron).
  • FERPA Export & Purge: One-click student JSON export, Gradebook CSV, and cascading deletion available to teachers anytime.
