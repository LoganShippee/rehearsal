Schools and privacy note

Written for district reviewers. It says what Rehearsal collects, where it is kept and how to delete it. If you need a form signed or a purchase order set up, use the contact card below.

Also: the full privacy policy, a one-page student data summary and an IT setup sheet.

What the classroom app collects: nothing

  • No account or login to teach in the Mac and Windows apps. Your classes, schedules and files stay on your device. The web version asks teachers to sign in (Google or an email code) and backs up settings, classes, schedules and events to their teacher account; library files (scores, PDFs, recordings) stay in the browser. It keeps working offline from a saved copy.
  • No ads, no analytics or tracking scripts, and no sale of data.
  • It works offline: display, tuner, metronome, sight reading, score practice and grading.
  • It needs the internet only for Online Homework, YouTube, Google Drive and update checks.
  • There is no automatic crash reporting. If a teacher chooses to send a bug report, they see the screenshot first and approve it before it is sent.

Where data lives and for how long

On our server

Audio is deleted automatically after 90 days. Scores stay until the teacher deletes them. Teachers can delete audio, a single student, or a whole class at any time.

On the student’s device

The newest 5 practice takes for each assignment are kept. If Wi-Fi drops, a recording is saved on the device and uploads when the connection returns.

Shared computers

Sessions on a shared Chromebook or computer expire after 24 hours.

Your classroom files

Classes, schedules and files stay on the teacher’s own device. They are not sent to us.

Third-party services

These are the outside services Rehearsal actually uses.

  • Cloudflare: hosting.
  • Resend: sends teachers their sign-in email codes.
  • Google sign-in: optional, for students whose school allows it.
  • YouTube and Google Drive: only if a teacher adds them to a class.
  • GitHub: update checks in the Mac and Windows apps.
  • Stripe: payments, only when billing is switched on. It is not switched on yet.

Student sign-in options

Class code and student code

Students enter the class code plus a personal 6-character student code. No student email is needed.

Google

Students can sign in with Google where their school allows it.

For school IT: allowing Google sign-in

Some districts only let approved apps use “Sign in with Google”. Teachers and students at those schools see “Access blocked” (error: admin_policy_enforced). Codes and the email code still work, so nobody is locked out.

  1. In the Google Admin console, open Security → Access and data control → API controls → Manage third-party app access.
  2. Add Rehearsal as an app by its OAuth client ID and set it to Trusted. The client ID is: 130764622805-uauoq1f4trsb50mtcu5vcla74tcia7gb.apps.googleusercontent.com
  3. Rehearsal asks only for basic sign-in details: name, email address and profile picture. It has no access to Drive, Gmail or Calendar.

Menu names in the Admin console can differ slightly. Questions: contact us.
