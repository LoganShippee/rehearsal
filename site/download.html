Rehearsal for Mac (v1.3.1)

Universal app for Apple Silicon and Intel Macs. Includes MuseScore .mscz conversion, Google Drive browser, and live window mirroring.

Download Rehearsal.zip
  1. Unzip Rehearsal.zip and drag Rehearsal into Applications. (Opening it from Downloads can block the mic and auto-updates.)
  2. Open Rehearsal. Because it isn't registered with Apple yet, macOS shows a one-time notice—click Done.
  3. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway. Needed only once.
No admin password required

Rehearsal for Windows 10 / 11 (v1.3.1)

Installs for your user account (%LOCALAPPDATA%\Programs\Rehearsal). Includes MuseScore .mscz conversion and Google Drive browser.

Download Installer (.exe) Portable .zip
  1. Run Rehearsal-Setup.exe (no school IT password needed).
  2. If Windows SmartScreen shows "Windows protected your PC", click More info → Run anyway. Needed only once.
  3. Automatic signed updates and 30-day local backups run on their own.

Rehearsal Web App

Works in Chrome, Safari, and Edge on Chromebooks, iPads, Macs, and PCs—offline after your first visit.

Open Web App
  1. Chrome / Edge: Click Install Rehearsal in the address bar (or ⋮ → Install).
  2. iPad / iPhone: Tap Share → Add to Home Screen in Safari to run full screen.
  3. Classes stay in that browser; use Setup → Settings → Export backup to move between computers.
